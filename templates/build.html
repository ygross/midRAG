HOW build_index.py WORKS
1
📄 EXTRACT — PDF → raw text
PyMuPDF (fitz) reads each page. Text is concatenated with page-break markers so we can track page numbers in metadata.
2
✂ CHUNK — Sliding window
Fixed: 400-char windows, 50-char overlap — overlap prevents cutting a sentence in half. Paragraph: splits at blank lines, preserving semantic boundaries.
3
🔢 EMBED — Sentence transformer
all-MiniLM-L6-v2 encodes each chunk in batches of 64. Output: 384-dim float32 vector per chunk. Runs on CPU (~1 min for 15 k chunks).
4
📐 NORMALISE — L2 norm
Each vector is divided by its magnitude so ‖v‖ = 1. This converts cosine similarity into a simple dot product — fast and exact.
5
💾 SAVE — numpy flat index
vectors.npy + chunks.json. No database. At 15 k chunks the flat dot-product scan takes <10ms — no HNSW needed (and no Windows bugs).
