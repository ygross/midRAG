🔬 Pipeline Trace — how evaluation metrics are computed ▶
EVALUATION LOOP
for question in gold_set (50 Qs):
retrieved = retrieve(q, k=k, strategy=s)
hit     = chunk_id_overlap OR same-page ±2
prec    = correct_chunks / k
answer  = generate(q, retrieved, model)
lat     = end_time − start_time
Hit@k = mean(hits) · Prec@k = mean(precs)
METRIC DEFINITIONS
H
Hit@k — Retrieval recall proxy
1 if ANY of the top-k retrieved chunks came from the correct source (exact chunk_id match OR same document within ±2 pages of the gold page). 0 otherwise. Averaged over all questions.
P
Precision@k — Retrieval quality
Fraction of the k retrieved chunks that came from the correct source document. Prec@5 = 3/5 = 0.60 means 3 of 5 chunks were relevant.
L
Latency — End-to-end time
Wall-clock time from question receipt to answer returned. Includes embedding (~8ms), vector search (<5ms), and LLM generation (0.5–3s depending on model).
★
Gold set — Ground truth
50 questions hand-written across 5 categories (factual 20, numerical 10, temporal 5, negation 8, comparison 7) with must_cite_chunk_ids specifying the correct source chunks.
